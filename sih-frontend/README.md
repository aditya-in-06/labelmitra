# LabelMitra — SIH Frontend

Responsive React + Vite frontend for the LabelMitra Legal Metrology inspection workflow.

## Included
- Legal Metrology inspection dashboard
- New inspection workflow
- Multi-photo package evidence upload/camera capture
- Inspection results view
- Responsive desktop and mobile layout
- LabelMitra branding on desktop and mobile
- Backend API integration via `VITE_API_BASE_URL`

## Not included
- Food Intelligence / consumer workflow
- Consumer routes and pages

## Run
```bash
npm install
npm run dev
```

For production, set `VITE_API_BASE_URL` to the deployed backend URL before building.
